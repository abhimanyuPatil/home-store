# Mission

Implement exactly one backend task.

Stop after completion.

---

# Read First

1. .codex/AGENTS.md
2. .codex/playbooks/common.md
3. .codex/playbooks/backend.md
4. docs/technology.md
5. docs/architecture.md
6. docs/api.md
7. Relevant backend task

---

# Workflow

1. Read the task.
2. Understand dependencies.
3. Review architecture.
4. Review existing code.
5. Implement only the assigned task.
6. Add or update tests.
7. Ensure build passes.
8. Ensure lint passes.
9. Mark task as **Implemented**.
10. Stop.

---

# Rules

- Never modify requirements.
- Never modify design.
- Never modify architecture.
- Never modify APIs.
- Never implement another task.
- Never refactor unrelated code.
- Follow all playbooks.
