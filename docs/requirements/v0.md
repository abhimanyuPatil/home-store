# Home Supplies Inventory App - Requirements

## Overview

The purpose of this application is to help users keep track of household supplies by maintaining:

* Storage location
* Exact subsection within the location
* Available quantity

This allows users to quickly identify where an item is stored and how much of it is currently available.

---

# Storage Hierarchy

A home contains multiple **Storage Locations**. Each storage location can contain multiple **Subsections**.

### Example Structure

```text
Cabinet
├── Top Shelf
├── Middle Shelf
└── Bottom Shelf

Fridge
├── Top Section
├── Middle Section
├── Vegetable Section
└── Masala Section

Drawer
├── First
├── Second
└── Third
```

---

# Supplies

Supplies represent household grocery or pantry items.

### Examples

* Oats
* Rice
* Salt
* Sugar
* Cumin Seeds
* Turmeric
* Lentils

---

# Mapping Supplies

Users should be able to map each supply to:

* Storage Location
* Storage Subsection
* Quantity

### Example

| Supply      | Location | Subsection     | Quantity |
| ----------- | -------- | -------------- | -------- |
| Oats        | Cabinet  | Top Shelf      | 400 g    |
| Rice        | Cabinet  | Bottom Shelf   | 5 kg     |
| Salt        | Drawer   | First          | 1 kg     |
| Cumin Seeds | Fridge   | Masala Section | 100 g    |

---

# Functional Requirements

## 1. Manage Storage Locations

Users should be able to:

* Create storage locations (e.g., Cabinet, Fridge, Drawer)
* Create subsections under each location
* Edit or delete locations and subsections

---

## 2. Manage Supplies

Users should be able to:

* Add new supplies
* Edit supply details
* Delete supplies

---

## 3. Map Supplies to Locations

Users should be able to assign a supply to:

* A storage location
* A subsection within that location
* A quantity

Each supply should have only one active storage location, and can have a back up storage location as well.

---

## 4. View Inventory

Users should be able to view a list of all supplies displaying:

* Supply name
* Storage location
* Storage subsection
* Current quantity

Example:

| Supply | Location | Subsection   | Quantity |
| ------ | -------- | ------------ | -------- |
| Oats   | Cabinet  | Top Shelf    | 400 g    |
| Rice   | Cabinet  | Bottom Shelf | 5 kg     |

---

## 5. Update Quantity

Users should be able to modify the quantity of any stored supply whenever it is consumed or replenished.

Example:

* Oats: **400 g → 250 g**
* Rice: **2 kg → 5 kg**
